## ML — strategy decided 2026-07 (classical ML, CPU-only Docker)

**Decision**: the MLX/ml-intern local-LLM training track is **parked** (Apple-Silicon-only inference incompatible with the self-hosted Docker target; see `docs/ML_INTERN.md` header). Strategic path: harden and improve the shipped `ml/` scikit-learn stack. Priorities: categorization accuracy > transfer detection > recurring detection.

**Track A — hardening (DONE 2026-07-10)**: fixed broken SQL in `ml/app/core/database.py` (train/recurring/transfer endpoints 500'd on every call since inception, masked by Laravel's graceful degradation); bearer-token auth (`ML_SERVICE_TOKEN`) + CORS removal + network isolation; deleted dead Celery scaffolding + legacy unversioned routers + `docker-compose.ml.yml`; queue worker added to `compose.ml.yml`; Python test suite (`ml/tests/`, 34 tests) + ruff + mypy; `EntityBehavior` trait removed (TypeError release blocker). Follow-up: CI job for `ml/` tests (needs `.github/` permission).

**Track B — quality roadmap (NEXT)**, full designs in the 2026-07-10 planning session (`~/.claude/plans/act-as-senior-ml-ai-fancy-squid.md`):

- B0: evaluation harness (temporal holdout + 5-fold CV, per-class metrics history JSON, metrics endpoint + settings UI); backtest script; export upgrades (booked_date/account_id, transfer-pairs task).
- B1: categorizer — merchant-normalized token feature, SGD→LogisticRegression (calibrated probabilities), delete broken `partial_train()`, per-class auto-apply thresholds, cold start (multilingual keyword→user-category concept table + instance-global model + merchant-memory fallback chain), wire `auto_apply_suggestions` (3-gate design), merchant-cluster labeling queue in admin UI.
- B2: transfers — deterministic tiers in PHP (fee-tolerant, no-IBAN, FX via ExchangeRateService), then supervised pairwise scorer (HistGradientBoosting on ~1370 linked pairs, Hungarian assignment); relax the Laravel re-validation gate for conf ≥0.90 or the ML path stays decorative.
- B3: recurring — consolidate on PHP `RecurringDetectionService` (delete Python module); extend heuristic (biweekly, MAD tolerance, day-of-month anchoring, missed-occurrence, price-change regimes); confirm/dismiss lifecycle already collects labels for a future learned ranker.
